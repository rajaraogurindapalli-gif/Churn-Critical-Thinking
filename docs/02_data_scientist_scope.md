# 02 – Scope of the Data Scientist

## In scope
- Problem reframing and hypothesis generation
- Data interrogation and quality assessment
- Quantitative comparison of competing explanations
- Building a simple, interpretable risk score or lightweight model
- Clear communication of findings, uncertainty, and next actions
- Delivering an interactive Streamlit app that can accept user-supplied data

## Out of scope (for the initial critical path)
- Large-scale production model deployment
- Full A/B test execution
- Complex black-box models under a tight deadline

## Deliverables
1. Reframed problem definition
2. Data evaluation summary
3. Multi-hypothesis analysis
4. Transparent risk score + Logistic Regression baseline
5. Live Streamlit app (synthetic / CSV / database)
6. Background documentation
