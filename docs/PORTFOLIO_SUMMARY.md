# Portfolio Summary

## Project Title
Critical Thinking Applied to Customer Churn

## One-line description
End-to-end Data Science project where I reframed a high-pressure churn request, evaluated competing drivers with evidence, and delivered a transparent risk score plus an interpretable Logistic Regression baseline inside a live Streamlit app.

## What I demonstrated
- Problem reframing under stakeholder pressure
- Structured data evaluation and multi-hypothesis testing
- Preference for interpretability over complexity
- Building a deployable Streamlit app that accepts synthetic data, CSV upload, or direct database connection
- Clear communication of findings and recommended next actions
